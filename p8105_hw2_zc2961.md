subway_raw =

This dataset records subway entrances and exits in NYC. After cleaning,
it contains 1868 rows and 19 columns, including line, station name,
station coordinates, routes served, entry permission, vending
availability, entrance type, and ADA compliance. I standardized the
column names, retained the requested variables, explicitly specified
data types, and converted entry from “YES”/“NO” to TRUE/FALSE. No
entrance/exit records were removed. The data are not yet tidy for
route-level analysis because route names are stored in eleven separate
columns, route1 through route11, instead of a single route-name column.

``` r
baseline_raw =
  read_csv(
    "data/data_mci/MCI_baseline.csv",
    skip = 1,
    na = c("", "NA", "."),
    col_types = cols(
      .default = col_double(),
      ID = col_integer()
    )
  ) |>
  clean_names() |>
  rename(baseline_age = current_age) |>
  mutate(
    sex = factor(
      sex,
      levels = c(0, 1),
      labels = c("Female", "Male")
    ),
    apoe4 = factor(
      apoe4,
      levels = c(0, 1),
      labels = c("Non-carrier", "Carrier")
    )
  )

baseline_excluded =
  baseline_raw |>
  filter(
    !is.na(age_at_onset),
    age_at_onset <= baseline_age
  )

baseline_df =
  baseline_raw |>
  filter(
    is.na(age_at_onset) | age_at_onset > baseline_age
  )
```

I skipped the first descriptive row, standardized the column names, and
renamed `current_age` to `baseline_age`. Sex and APOE4 carrier status
were encoded as factors. I treated “.” as a missing onset age,
indicating no MCI during the recorded follow-up, and excluded
participants whose onset age was at or before baseline.

For the amyloid file, I skipped the first descriptive row, cleaned the
column names, treated “NA” and “Na” as missing-value markers, and

for matching and reshaped the measurements into the variables `id`,
`time`, and `amyloid_ratio`. The time variable denotes years since
baseline: 0, 2, 4, 6, and 8. Missing biomarker values were retained. The
tidy dataset contains 487 participants and 2435 participant-time rows.
